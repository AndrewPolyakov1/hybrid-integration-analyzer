# Гибридный анализатор на основе спецификации LibSL

В данном репозитории представлен гибридный анализатор для выявления дефектов интеграции на основе спецификации на языке
LibSL.

## Структура проекта

- [`agent`](./agent) - Java-агент, отвечающий за снятие трасс
- [`analyzer`](./analyzer) - анализатор, отвечающий за анализ
- [`libsl-parser`](./libsl-parcer) - парсер спецификации LibSL

## Quickstart guide

### Сборка проекта

Для сборки используется Maven.

**Парсер LibSL**

Перед сборкой модулей требуется установить парсер LibSL в локальный репозиторий `.m2`, так как он требуется как
зависимость для других модулей.

```bash
cd ./libsl-parcer && mvn -U clean install
```

**Агент**

Для сборки агента требуется выполнить следующее:

```bash
cd ./agent && mvn -U clean package
```

В директории `./agent/target` появится JAR файл - агент.

Для подключения агента к целевой программе требуется выполнить:

```bash
java -Dlibsl.spec=spec.libsl  -javaagent:universal-java-agent-1.0.jar -jar <your_app.jar> [args...]
```

где `spec.libsl` - файл спецификации LibSL.

В процессе работы в директории появится файл в формате `JSONL`.

**Анализатор**

Для сборки анализатора требуется выполнить следующее:

```bash
cd ./analyzer && mvn -U clean package
```

В директории `./analyzer/target` появится JAR файл - анализатор.

```bash
java -jar <analyzer.jar> <LibSL spec> <trace file>
```
